## 制作アプリのタイトル
ひとこと日記
## 制作アプリの説明（40文字程度）
Twitterみたいに今日あった出来事を呟いて記録する日記形式のアプリ
## 工夫した点・こだわった点
出来事はテキストで、感情はボタン形式で記録できるようにしました。
## 次回トライしたいこと（または機能）
-過去の出来事を見返すときに、日付検索したり、削除機能をつけたりしたい
-絶妙にデザインがダサいのでなんとかしたい
-どの感情がどのくらいの割合を占めているのか統計を取れるようにしたら面白そう
## 備考（感想、シェアしたいこと等なんでも）
-やりたいことやつけたい機能は沢山あるのに、それをするための思考フローがまだ身についていなくて悔しいのと、デザインセンスがないのでもっとスタイリッシュにできるようになりたいです、、！
-localStrageの機能を使って、日記以外にも家計簿や目標逆算シート、得意先毎の記録、アポイントリスト、色々作れる幅が広がるなぁと思いました。
